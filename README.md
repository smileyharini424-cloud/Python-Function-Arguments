# Python Function Arguments

## Explanation

Function arguments are values passed to a function when it is called. Python supports different ways of passing arguments to functions.

This program demonstrates:

* Positional arguments
* Keyword arguments
* Default arguments
* Variable-length arguments

## Problem Statement

Write a Python program that demonstrates different types of function arguments using simple functions.

## Features

* Demonstrates positional arguments
* Demonstrates keyword arguments
* Demonstrates default arguments
* Demonstrates variable-length arguments
* Shows how values are passed to functions

## How It Works

The program defines separate functions for different argument types.

### Positional Arguments

Arguments are passed according to their position.

### Keyword Arguments

Arguments are passed using parameter names.

### Default Arguments

A default value is used when no argument is provided.

### Variable-Length Arguments

`*args` allows a function to accept multiple positional arguments.

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Define functions with different argument types.
3. Call the functions.
4. Pass arguments using different methods.
5. Display the results.
6. End the program.
